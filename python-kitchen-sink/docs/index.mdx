Personal Python **3.14** reference for DSA and LLD interviews. Each page has a short explanation, copy-paste syntax, and links to the official docs.

1. [Basics](/basics): Loops, conditionals, functions, exceptions and core syntax.
2. [Built-in data structures](/data-structures): list, tuple, dict, set, str and string formatting.
3. [Built-in functions](/builtins): len/min/max, sorted, zip, any/all, numeric and conversion built-ins.
4. [collections](/collections): deque, defaultdict, Counter, OrderedDict, namedtuple.
5. [heapq](/heapq): Priority queues: min-heap, max-heap, tie-breaking, k-way merge.
6. [bisect](/bisect): Binary search on sorted lists.
7. [itertools](/itertools): Prefix sums, combinatorics, grouping and iterator helpers.
8. [functools](/functools): Memoization, custom comparators, reduce, partial.
9. [math & numbers](/math): gcd/lcm, integer sqrt, combinatorics, logs, modular arithmetic.
10. [OOP for LLD](/oop): Classes, inheritance, ABCs, protocols, dataclasses, enums, type hints.
11. [Advanced Python for LLD](/advanced): Generators, decorators, context managers, concurrency, datetime, uuid.
12. [LLD design patterns](/design-patterns): Common GoF patterns written idiomatically in Python.
